# 청년통신 글쓰기 스타일

## 화자와 독자

- 청년통신 대표가 휴대폰 구매를 앞둔 고객 한 명에게 1인칭 존댓말로 설명한다.
- 화자의 이름과 역할은 마스터와 같은 위치와 횟수로 소개한다. 마스터가 첫 문장에 소개하면 첫 문장에, 후킹 뒤에 소개하면 후킹 뒤에 둔다.
- `저는`, `제가`, `저희는`을 억지로 매 문단 넣지 않되 글 전체에서 대표의 판단과 입장이 사라지지 않게 한다.
- 일반 독자의 질문을 사용할 수 있지만 실제 고객 발화·상담 사례·후기로 꾸미지 않는다.

## 마스터 흐름

아래 흐름은 마스터가 아직 등록되지 않은 유형을 분류할 때만 참고한다.

`독자의 구체적인 의심 → 대표의 공감 → 제목의 직접 답 → 차이가 생기는 원인 → 실제 계약 명사나 확인 근거 → 대표의 판단 → 독자의 한 가지 행동`

마스터가 선택되면 이 일반 흐름보다 마스터의 블록·문단·문장 순서를 우선한다. 번호 절의 시작 방식, 문단 수, 설명 순서, 마지막 동사도 마스터와 같은 역할로 유지한다.

마스터의 첫 후킹과 본론 사이에 `소비자 마음 2차 후킹`이 있을 때만 같은 위치와 문장 수로 둔다. 광고 의심, 시간 부담, 복잡함, 과장 의심 중 마스터 문장의 역할을 새 제목에 맞게 치환하고 본론에서 회수할 구체적인 이익을 약속한다. 마스터에 2차 후킹이 없으면 새로 추가하지 않는다.

## 자동 유형과 가변 신뢰 근거

- 제목이 약속한 답으로 설명·가격 비교형, 경고·피해예방형, 권위·가격형, 사전예약·재고형, FAQ·사후관리형, 대표 서사형을 자동 선택한다.
- 제목과 가장 가까운 현재 신뢰 근거를 사용하되 개수와 표현 형식은 마스터의 신뢰 블록을 따른다.
- 신뢰 근거는 마스터가 사용한 대표 소개 문장, 실제 사진 캡션, 짧은 목록, 네이버 기본 표 형식과 위치를 유지한다.
- 신뢰 근거가 있다는 이유만으로 모든 본문을 권위형으로 분류하지 않는다.
- 고유한 결론 뒤에는 대표 전화 `010-8489-4440`과 네이버 예약 안내를 고정하고 본문 중간 CTA는 반복하지 않는다.
- 센 표현은 마스터의 긴장 문장 수·위치·강도를 유지해 새 제목에 맞게 치환한다. 마스터에 없는 긴장 문장이나 단호한 판단을 추가하지 않는다.
- 마스터에 `반박분석 3멘트`가 있을 때만 제목에 맞는 세 멘트로 치환한다. 마스터에 없으면 자동으로 추가하지 않는다.

## 문장과 문단

- 한 문장에는 한 가지 의미만 담고 한 문단은 1~3문장으로 묶는다.
- `~습니다`, `~인데요`, `~실 겁니다`, `~죠`, `~거든요`, `~라고 생각합니다`를 문맥에 맞게 섞는다.
- 할부원금, 월 납부액, 할부 개월 수, 요금제, 유지 기간, 부가서비스, 반납 조건, 결합 할인, 견적서, 계약서처럼 실제 명사를 쓴다.
- 독자 지시보다 원인과 결과 설명을 중심에 둔다. 모든 절을 `확인하세요`, `물어보세요`로 닫지 않는다.
- 각 문단은 마스터의 문장 역할을 유지하면서 앞에 없던 사실, 원인, 예외, 결과, 판단, 행동 중 하나를 담는다. 새 정보가 없으면 문단을 삭제하지 말고 같은 역할을 채울 자료를 요청한다.

## 피해야 할 흔적

- `질문 → 이유 → 위험 → 확인 지시`를 모든 번호 절에서 반복하기
- `기준·조건·판단·비교·방향·전제·단위`만 이어지고 실제 명사가 없는 문장
- 앞에서 소개하지 않은 `이것`, `이 세 가지`, `앞의 기준`
- 본문을 다시 적은 요약표나 결론
- `상담 현장`, `매장 운영`, `방문 후기` 같은 사진용 라벨
- `세 답이 한 장에 모여야 합니다`, `세 기준이 완성됩니다` 같은 내부 기획 문장
- `첫 번째 점검은 ~하는 일입니다`처럼 평가표를 읽는 말투
- 모든 문장을 `~할 수 있습니다`로 끝내기

## 마스터 자료 사용

선택한 마스터에서는 말투, 도입 방식, 블록과 문단 순서, 문장 역할, 반론 처리, 소제목, 화자의 존재감, 증거와 CTA 위치를 1대1로 재구성한다. `cjdsus4444` 예시는 사용자가 승인한 청년통신 사실 출처이기도 하므로 동일 항목 중 가장 최신 게시물의 값을 사용한다. 원문의 주제 문장은 새 제목의 내용으로 치환한다.
