# 제목 약속 해석

사용자가 확정한 제목은 임의로 바꾸지 않는다. 근거가 없거나 답을 만들 수 없으면 원고를 쓰지 않고 근거를 요청한다. 제목 변경은 사용자의 허용을 받은 경우에만 한다.

## 제목에서 글 유형 자동 선택

- `이유`, `차이`, `비교`, `구매법`, `고르는 법`: 설명·가격 비교형
- `사기`, `호구`, `손해`, `주의`, `피해야`, `절대`: 경고·피해예방형과 강한 경고 표현
- `왜 싼`, `생활의 달인`, `1위`, `판매량`, `대표`, `믿을 근거`: 권위·가격형과 확인된 강한 가치 표현
- `사전예약`, `재고`, `입고`, `출시`, `당일`: 사전예약·재고형
- `질문`, `BEST`, `준비물`, `위치`, `영업시간`, `서비스센터`: FAQ·사후관리형
- `창업`, `시작`, `경력`, `철학`, `운영 선택`: 대표 서사형

제목이 두 유형을 함께 약속하면 두 약속을 모두 가진 마스터 한 편을 찾는다. 두 유형의 글을 결합하지 않는다. 맞는 마스터가 없으면 대표글 한 편을 요청한다. 선택한 신뢰 근거가 있다는 이유만으로 모든 글을 권위형으로 분류하지 않는다. `반박분석 3멘트`는 선택한 마스터에 있을 때만 같은 위치와 문장 수로 사용한다.

## 질문 N가지

- 실제로 매장에서 사용할 수 있는 질문 N개를 제시한다.
- 질문마다 직접 답, 금액이나 계약 내용에 미치는 결과, 견적서·계약서에서 연결할 실제 항목을 둔다.
- 서로 겹치는 질문을 표현만 바꿔 N개로 세지 않는다.
- N개의 답과 각 답의 설명 재료가 없으면 자료를 요청한다.

## 이유

- 원인과 결과를 설명한다.
- 확인 순서나 행동 목록으로 바꾸지 않는다.
- 매장이 좋다는 주장만 나열하지 않는다.

## 하는 법

- 독자가 사용할 수 있는 행동 순서를 설명한다.
- 각 단계에 실제 명사, 서류, 확인 대상을 연결한다.
- 원인을 약속한 글처럼 이론 설명만 이어 가지 않는다.

## 차이 N가지

- 서로 다른 실제 차이 N개와 차이가 생기는 원인을 설명한다.
- 주의사항·확인 순서·같은 차이의 결과를 별도 차이로 세지 않는다.

## 제목의 `이것`

- 도입 첫 두 문단 안에서 구체 명사로 공개한다.
- 공개 전에는 `이것`, `이 세 가지`, `앞의 기준`으로 다시 가리키지 않는다.
- 독자가 제목을 클릭한 뒤 답을 미루는 장치로 사용하지 않는다.

## 숫자와 강한 주장

비율, 가격, 할인액, 손해액, 판매량, 문의량, 경력, 순위, 수상, 방송, 환불·보장은 `사용 가능` 사실 ID가 있을 때만 제목에 쓴다. 물음표나 인용부호로 근거 검증을 우회하지 않는다.

## 내부 제목 계약

초안 전에 다음만 적고 본문에는 노출하지 않는다.

```text
제목이 약속한 답의 종류:
필요한 답 개수:
각 답의 한 문장 요약:
각 답의 사실 ID:
상태: 작성 가능 | 자료 요청
```
