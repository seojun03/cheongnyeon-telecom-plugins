# 편집 플로우 사이클

주기적 자동 발행, 매일 다른 글, 반복 사이클을 요청받았을 때 이 문서를 처음부터 끝까지 읽고 적용한다.

이 문서는 주기별 주제와 제목 유형을 고르는 참고자료다. `sungji_dongtan` 188편 압축 라이브러리는 주제·제목 장치·독자 질문·답변 의제만 결정한다. 글의 설득 구조·말투·훅 위치·CTA·꾸미기는 제목과 호환되는 `cjdsus4444` 주 마스터 한 편이 전부 결정한다. 두 출처를 조합해 새 구조를 만들지 않는다. 사실은 최신 청년통신 사실 레코드만 사용한다.

## 설계 단위

다섯 축을 기록하되 독립적으로 선택하거나 조합하지 않는다.

1. `flow`: 선택한 마스터가 가진 큰 순서
2. `angle`: 이번 글이 설명할 핵심 소재
3. `hook`: 선택한 마스터의 첫 문제 제기 방식
4. `cta`: 선택한 마스터의 마지막 행동
5. `brandOverlay`: 선택한 마스터의 신뢰 근거 개수·형식·위치와 최신 청년통신 사실

같은 소재라도 제목 유형이 다르면 그 유형의 마스터도 달라질 수 있다. 제목이 확정된 뒤에는 선택한 마스터의 플로우·훅·CTA를 바꾸지 않는다.

## 8개 플로우

| ID | 이름 | 섹션 역할 순서 | 대표 제목 약속 |
|---|---|---|---|
| `warning_red_flags` | 경고·레드플래그 | 상황 또는 인용 → 위험 신호 → 손실 원리 → 확인 행동 → 중단 기준 | `이런 말 들으면 멈추세요`, `피해야 할 3가지` |
| `mistake_diagnosis` | 실수·후회 진단 | 독자 상황 → 반복 실수 → 결과 → 자가진단 → 대체 행동 | `후회하는 사람 공통점`, `대부분 놓치는 실수` |
| `selection_checklist` | 선택 기준·체크리스트 | 제목과 사실 팩에서 도출한 서로 다른 확인 항목 → 필요한 현장 질문 또는 실제 비교값 | `개통 전 확인할 3가지`, `매장 선택 기준` |
| `price_mechanism` | 가격·시장 구조 | 가격 차이 질문 → 비용·수익 구조 → 두 운영 방식 → 소비자 결정법 | `가격이 다른 이유`, `싸게 파는 구조` |
| `myth_comparison` | 오해 반전·양자 비교 | A·B 정의 → 흔한 오해 → 각각의 이익과 예외 비용 → 판단표 | `A보다 B 먼저`, `A와 B 중 무엇이 유리한가` |
| `specific_situation` | 특정 상황 해결 | 구체 상황 → 준비물 또는 조건 → 실패 지점 → 실행 단계 → 최종 확인 | 중고폰·외국인·보안·기기변경 등 상황별 가이드 |
| `trust_story` | 신뢰 증거·방문 이유 | 예상 반론 → 검증 가능한 증거 → 고객 맥락 → 운영 원리 → 선택 기준 | `다시 찾는 이유`, `멀리서 방문하는 이유` |
| `insider_letter` | 업계인의 편지·고백 | 이해관계 인정 → 내부자 관찰 → 핵심 경고 하나 → 작동 원리 → 구매자 행동 | `판매자가 드리는 경고`, `현장에서 알게 된 사실` |

기존 제목이 있으면 제목 계약과 호환되는 마스터 한 편을 고른다. 제목도 생성하는 작업이면 등록된 마스터가 있는 유형을 먼저 고르고 그 마스터가 실제로 회수할 수 있는 제목을 만든다.

## 소재·훅·CTA 풀

### 소재

- 24개월 총납입금
- 약정과 할부 기간
- 요금제와 부가서비스
- 중고폰 반납
- 번호이동과 기기변경
- 매장 유형
- 판매량과 마진 구조
- 재고와 사후관리
- 운영 기간과 신뢰 근거
- 외국인 개통
- 휴대폰 보안·생활 팁

사용자 자료와 공개 근거가 없는 숫자, 판매량, 가격, 할인, 환불, 후기, 방송, 수상은 소재로 선택하지 않는다.

### 훅

- `seller_quotes`: 실제로 들을 법한 짧은 상담 문장
- `skeptical_objection`: 광고글 또는 판매자를 못 믿겠다는 반론
- `paired_questions`: 두 선택지를 두고 생기는 질문
- `customer_scene`: 구매 전후의 구체적인 한 장면
- `counterintuitive_question`: 같은 상품의 가격이 다른 이유 같은 반전 질문
- `evidence_first`: 확인된 증거를 먼저 보여준 뒤 문제 제기
- `urgent_warning`: 실제 행동으로 막을 수 있는 위험 경고
- `rebuttal_triplet_seller`: 경계할 판매자 멘트 세 개를 먼저 보여 주고 각각 반박
- `rebuttal_triplet_reader`: 독자의 의심 세 개를 먼저 말한 뒤 공감하고 각각 반박

### CTA

- `compare_two_quotes`: 같은 조건으로 두 곳 이상 비교
- `ask_total_cost`: 월 납부액이 아닌 총납입금 질문
- `get_it_in_writing`: 조건을 계약서 또는 서면과 대조
- `run_self_check`: 본문 체크리스트로 스스로 점검
- `optional_consult`: 꼭 청년통신이 아니어도 된다고 밝힌 뒤 선택 상담
- `reserve_visit`: 확인된 연락처와 네이버 예약 안내

CTA의 주행동과 위치는 마스터를 따른다. 대표 전화와 네이버 예약은 최신 고정값으로 치환한다.

## 최근 3편 회전 규칙

`state/recent-articles.json`에는 최근 완성 글 3개만 둔다.

1. `scripts/select_topic_idea.py`는 최근 3개의 `ideaType`, `titlePatternId`, `ideaReferenceUrl`과 겹치지 않는 후보를 우선한다.
2. 정밀작성모드에서 후보 3개를 낼 때는 후보끼리도 유형·패턴·링크가 가능한 한 겹치지 않게 한다.
3. 호환되는 청년통신 마스터가 등록된 후보만 자동 완성에 사용한다.
4. 사용자가 제목·유형을 직접 지정하면 그 지시를 우선하되 발행 후 실제 사용값을 기록한다.
5. 글을 발행한 뒤 `scripts/record_article_state.py`로 새 항목을 맨 앞에 넣고 네 번째인 가장 오래된 항목을 삭제한다.
6. 같은 마스터를 다시 쓰더라도 새 제목의 독자 질문·답변 명사·상담 장면은 달라야 한다. 마스터의 고정 구조는 중복으로 보지 않는다.

## 선택 절차

1. 최근 3편 이력을 읽는다.
2. 메인키워드로 `scripts/select_topic_idea.py`를 실행한다.
3. 외부 아이디어 프로필의 제목 장치·독자 질문·답변 의제만 고정하고 외부 사실은 폐기한다.
4. 청년통신 사실표에서 제목을 문자 그대로 증명할 사실만 고른다.
5. 제목을 만든 뒤 `scripts/validate_title.py`를 통과시킨다.
6. 선택 프로필과 호환되는 `cjdsus4444` 주 마스터 한 편을 선택한다.
7. 주 마스터의 플로우·훅·CTA·증거·꾸미기·사진 위치를 고정하고 새 내용만 치환한다.
8. 발행 게이트를 통과한 뒤 이력을 기록한다.

이력은 다음 필드를 보존한다.

```json
{
  "title": "완성 제목",
  "mainKeyword": "광주 휴대폰 계약",
  "ideaReferenceId": "sungji-로그번호",
  "ideaReferenceTitle": "아이디어 출처 제목",
  "ideaReferenceUrl": "https://blog.naver.com/sungji_dongtan/로그번호",
  "ideaType": "fraud-prevention",
  "titlePatternId": "keyword-warning-loss",
  "writingMasterId": "warning-seller-lines-01",
  "writingReferenceUrl": "https://blog.naver.com/cjdsus4444/로그번호",
  "writtenAt": "YYYY-MM-DD"
}
```

## 2021 지정 원문 기록

지정 원문 [화성 핸드폰 가게, 상위 1% 매장에서 싸게 사는 법 알려드립니다](https://blog.naver.com/sungji_dongtan/222515090668)은 `price-mechanism` 주제·제목 아이디어 프로필이다. 현재 청년통신 글의 말투·문단 구조·꾸미기·사진 마스터로 사용하거나 청년통신 마스터와 구조를 조합하지 않는다.

원문의 역할 순서는 `운영 성과 훅 → 가격 불안 → 동네 소매점의 비용 구조 → 대량 판매·도매 해결책 → 비독점 조언 → 연락처·지도`다.

선택기가 이 글을 고르면 다음 설득 기능만 제목·답변 기획에 사용할 수 있다.

1. 확인된 청년통신 증거 박스를 배치한다.
2. 메인키워드와 연결되는 독자의 가격·계약 고민을 제시한다.
3. 검증 가능한 총납입금, 요금제, 할부, 판매 구조만 설명한다.
4. 동일 조건 비교와 계약서 확인처럼 독자가 실행할 기준으로 회수한다.
5. 꼭 청년통신이 아니어도 된다는 완충 뒤 확인된 연락처·예약·지도를 배치한다.

원문의 `상위 1%`, 업체 수익, 판매량, 도매 구조, 전화번호는 청년통신 사실처럼 옮기지 않는다. 이 역할 순서도 청년통신 본문 구조로 복제하지 않고, 실제 본문 순서는 선택한 `cjdsus4444` 주 마스터가 결정한다.
