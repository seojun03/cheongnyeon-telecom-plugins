## 제목에 따른 세 가지 리듬

### 1. 순위형 경고

`판매 현장 문장 3개 → 짧은 판정 → 현장 사진 → 화자 자격·작성 의도 → 혜택 표 → 위험 1·2·3 → 각기 다른 손실 과정과 행동 → 후기·신뢰 자료 → 비교 권유 → 연락 표·지도`

다음 제목에 사용한다.

- `3가지`, `사기 수법`, `이 말`, `주의`, `손해`, `계약서에서 찾을 것`
- 업계 경고형, 3가지 계약 점검형, 후회 공통점형

각 항목의 `직접 답`, `확인된 판매 문장·상황`, `손실 원리`, `구체 행동` 유무와 순서·길이·문장 수는 선택한 마스터의 대응 항목을 그대로 따른다. 내용만 새 제목의 확인된 위험과 행동으로 바꾼다.

### 2. 핵심 기준 공개

`독자 질문 2~3개 → 현장 사진 → 화자 자격 또는 문제 이해 → 선택 비강요 → 혜택 표 → 글 앞 20~25%에서 핵심 기준 공개 → 작동 원리 → 쉬운 A/B 비교 → 소비자가 찾는 법 → 후기·증거 자료 → 비교 권유 → 고정 연락·예약 마감`

다음 제목에 사용한다.

- `이것`, `단 한 가지`, `먼저 봐야 할 기준`, `왜 가능한가`
- 숨은 기준 공개형, 가격 구매법형 일부, 신뢰 근거형 일부

‘이것’을 끝까지 숨기지 않는다. 공개 직후에는 그 기준이 결과를 바꾸는 인과를 설명하고, 다음 절에서 소비자가 직접 검증하는 방법을 준다. 시점성 재고나 수량은 `temporary_information.md`의 최신 사용 가능 사실만 쓴다.

### 3. 반론·운영 근거

`고객 불만 2~3개 → 독자 동일시 → 현장·자격 사진 → 화자 자격과 위험 → 선택 비강요 → 혜택 표 → 굵은 원인 질문 → 구조적 원인 사슬 → 현장/GIF → “당신들은 무엇이 다른가” 반론 → 운영 근거 → 증거 사진 → 일반 매장 선택 원칙 → 고정 연락·예약 마감`

다음 제목에 사용한다.

- `왜 이런 말이 생겼나`, `무엇이 다른가`, `믿을 근거`, `운영 방식`
- 신뢰 근거형

이 리듬은 번호 인용 박스를 강제로 세 개 만들지 않는다. 일반 문단 안의 짧은 굵은 질문으로 원인과 반론을 넘긴다. 근거가 없으면 자사 우월성 대신 소비자가 확인할 운영 기준으로 바꾼다.

## 문장 편집 규칙

- 현업 대표 또는 전문가가 독자 한 명에게 말하는 1인칭 존댓말이다.
- 한 의미 덩어리를 1~3문장으로 묶는다. 짧은 문단과 긴 문단을 섞고 연결어만 있는 줄은 실제 전환 기능이 있을 때만 사용한다.
- 짧은 직접화법은 독자 질문, 고객 불만, 예상 반론에만 쓴다.
- 질문 뒤에는 공감이나 직접 답을 붙인다. `결론부터`, `이유는`, `여기까지 읽으셨다면` 같은 전환어를 항목마다 반복하지 않는다.
- `~습니다/~합니다`를 중심으로 `~인데요`, `~실 겁니다`, `~라고 생각합니다`, 짧은 연결형을 섞는다.
- 선택 비강요 문장은 도입 1회, 비교 권유는 결론 1회만 둔다. 같은 저압 CTA를 여러 표현으로 반복하지 않는다.
- 최근 글과 주제 명사·사례·설명 내용이 겹치면 새 제목 내용으로 다시 치환하되, 마스터의 도입 위치·전환·결론·CTA 역할·비유 위치는 바꾸지 않는다.
