## 공통 독자 효익

특정 매장을 선택하지 않아도 사용할 수 있는 비교 기준, 확인 방법 또는 피해예방 행동을 제공한다. 브랜드 증거는 정보의 신뢰를 보조할 뿐 정보 자체를 대신하지 않는다.

마스터에 있을 때 해석할 기능:

`독자 상황·위험 훅 → 글쓴이의 자격과 의도 → 정보 약속 → 핵심 기준 → 질문·경고 → 원리 또는 피해 시나리오 → 확인·회피 행동 → 증거 → 기준 요약 → 저압 CTA`

위 기능의 유무와 순서는 마스터를 그대로 따른다. 제목에 맞는다는 이유로 새 기능을 추가하거나 표·요약을 빼지 않는다.

신뢰 근거의 개수·형식·위치는 마스터를 따르고, 내용만 제목과 가장 가까운 현재 사실로 교체한다. 신뢰 근거는 정보형의 직접 답이나 번호 항목으로 세지 않는다.

## 하위 변형 선택

### 설명·비교형

구매 기준, 업계 원리, 선택 방법처럼 이해와 비교가 목적일 때 사용한다.

`검색 혼란`, `활용 가능한 정보 약속`, `업계 원리`, `쉬운 비교`, `확인 방법`, `증거` 중 마스터에 있는 기능만 같은 순서로 사용한다.

- 질문 뒤에 원리 설명을 빠르게 붙인다.
- 마트·도매처럼 익숙한 비유로 구조를 설명한다.
- 비교표로 원리를 실제 판단 기준으로 바꾼다.
- 강조는 가볍게 유지하고 읽는 흐름을 우선한다.
- 대표 개인 서사의 유무와 위치는 마스터를 따른다. 마스터에 있으면 생략하지 않는다.

### 경고·피해예방형

계약 조건, 비용 손실, 오해하기 쉬운 안내처럼 즉시 피해야 할 위험을 설명할 때 사용한다.

`확인된 위험 문구 또는 독자 질문`, `짧은 경고`, `손실 원리`, `회피 행동`, `비교 권유` 중 마스터에 있는 기능만 같은 순서로 사용한다.

- 실제 상담 문구는 사용자 자료나 확인된 근거가 있을 때만 인용한다. 그 외에는 실제 사례처럼 꾸미지 말고 독자에게 직접 묻는 질문으로 쓴다.
- 본문의 순위형 또는 번호형 인용 소제목 수는 마스터와 동일하게 유지한다.
- 각 위험 항목의 문제, 원리, 결과, 확인 행동 순서·길이·문장 수는 마스터 대응 항목을 그대로 따른다.
- 각 항목의 확인·거절 행동은 대상과 동사가 서로 달라야 한다. `절대 말만 듣고 넘기지 마세요` 같은 범용 경고를 모든 항목 끝에 반복하지 않는다.
- 경고의 강도는 높일 수 있지만 확인되지 않은 상대를 범죄자처럼 단정하지 않는다.
- 결론에서는 즉시 문의를 재촉하지 않고 여러 곳을 비교하고 신중히 판단하도록 권한다.
- 선택한 마스터에 세 개의 판매자 멘트 또는 독자 반론이 있을 때만 [rebuttal-analysis-three-lines.md](rebuttal-analysis-three-lines.md)로 같은 역할을 치환한다. 마스터에 없으면 다른 글에서 가져오지 않는다.

사용자가 하위 변형을 지정하면 우선한다. 지정하지 않으면 제목을 기준으로 자동 선택한다. 일반 가이드·이유·차이·구매법은 설명·비교형, 사기·호구·손해·주의·계약 기만은 경고·피해예방형으로 선택한다.

## 초보자 설명 논리

휴대폰을 처음 알아보는 독자라도 두 기준 글을 조합하지 않는다. 제목과 가장 가까운 청년통신 마스터 한 편을 선택하고, 외부 기준 글의 구조와 사실은 가져오지 않는다. 청년통신 수치·사례·매장 정보는 최신 사실 레코드의 값으로 치환한다.

- 도입은 독자의 구체적인 상황이나 질문 하나로 시작하고 이번 글에서 답할 주제를 바로 밝힌다. 실제 고객 발화는 제공된 경우에만 인용한다.
- 번호이동과 기기변경처럼 헷갈리는 두 선택지는 각각 무엇인지 먼저 한 문장으로 설명한다.
- 한쪽이 늘 정답이라고 단정하지 않는다. 일반적으로 유리한 이유를 설명한 뒤 반대쪽이 유리한 경우도 알려준다.
- 비교는 월요금 하나가 아니라 계약이 끝날 때까지 드는 전체 금액과 사라지는 할인까지 포함한다.
- `3가지` 제목은 각 절의 답을 첫 문장에 공개하고 서로 겹치지 않는 세 규칙으로 나눈다.
- 각 규칙의 쉬운 뜻, 돈이나 선택이 달라지는 이유, 실제 질문의 순서와 표면 구조는 마스터 대응 규칙을 따른다.
- 마지막에는 내용을 다시 길게 요약하지 않고 가장 먼저 확인할 숫자 하나와 질문 하나만 남긴다.
- `같은 견적으로 인정할 조건`, `공통 전제`, `판단 단위`, `운영 기준`처럼 내부 편집자가 쓰는 말을 독자 문장으로 사용하지 않는다.

## 자극형 경고 카피

제목이 사기·호구·손해·주의·피해야 할 조건을 약속하면 별도 요청이 없어도 경고·피해예방형 위에 자극형 카피 모드를 자동 적용한다. 사용자가 `자극적으로`, `세게`, `클릭하게`, `센 제목`, `사기 수법 톤`을 요청한 경우에도 동일하게 적용한다.

### 적극 사용할 수 있는 표현

- `사기 수법?`
- `불법일까?`
- `무조건 피해야 할 조건`
- `절대 그냥 넘기지 마세요`
- `호구 되기 싫다면`
- `이 말 들으면 바로 멈추세요`
- `모르면 당할 수 있습니다`
- `그대로 계약하면 손해 볼 수 있습니다`

### 제목 공식

- `[지역+업종 키워드]? 모르면 당하는 사기 수법 3가지`
- `[업종 키워드] 불법일까? 계약 전 확인할 조건`
- `[업종 키워드], 호구 되기 싫다면 무조건 보세요`
- `[조건명], 이 말 들으면 바로 멈추세요`

### 근거가 부족할 때의 사용 규칙

- `사기`는 제목·검색어·수법 패턴·의문형으로 사용할 수 있다. 특정 개인·업체를 `사기꾼` 또는 `사기업체`라고 단정하지 않는다.
- `불법`은 `불법일까?`, `불법 여부를 확인해야 하는 조건`처럼 질문과 확인 행동으로 연결한다.
- `무조건`과 `절대`는 `무조건 계약서 확인`, `절대 서두르지 마세요`처럼 독자의 안전 행동에 사용한다. 할인·절약·효과를 보장하는 문장에는 쓰지 않는다.
- `폰팔이`는 업계 전체의 검색어 또는 일반적 화법으로 사용할 수 있지만 특정 개인·업체를 지칭하지 않는다.
- `호구`는 `호구 되기 싫다면`처럼 훅에 사용할 수 있지만 독자에게 `이미 호구다`라고 직접 낙인찍지 않는다.
- 도입 초반에 `특정 업체를 단정하기보다 계약 전에 확인할 조건을 알려드리겠습니다`처럼 짧게 범위를 정리한다. 긴 면책문으로 긴장감을 끊지 않는다.

### 자극성 유지

- 첫 5문단 안에 위험 문구, 강한 결론, 독자가 확인할 행동을 모두 제시한다.
- 위험 항목은 순위형 또는 `1·2·3` 구조로 잘게 나눈다.
- 빨강은 위험어와 행동어, 노랑은 최중요 경고 1~2개에 사용한다.
- 강한 경고 뒤에는 실제 확인 질문이나 회피 행동을 반드시 붙인다.
- 본문 전체를 고함처럼 쓰지 말고 일반 설명 문단으로 호흡을 조절한다.

## 공통 구조와 문장 리듬

다음은 마스터 구조를 분석할 때 이름 붙이는 구성 요소다. 마스터에 있는 요소만 같은 순서와 개수로 사용한다.

- 독자의 구체적인 상황이나 질문
- 근거가 있을 때의 현장 경험·자격
- 글에서 바로 알려 줄 답
- 서로 다른 논거와 실제 확인 행동
- 실제 증거 이미지 또는 실제 값을 비교하는 표
- 독자가 스스로 할 한 가지 행동
- 고유 결론 뒤의 고정 연락·네이버 예약 블록

- 예상 질문은 한 번에 1개씩 사용한다.
- 한 의미 덩어리를 1~3문장으로 묶고 문단 길이를 일부러 같게 만들지 않는다.
- 전문용어보다 소비자가 이해할 수 있는 비유와 상황을 사용한다.
- 결론은 브랜드 칭찬보다 독자의 판단 기준으로 마무리한다.
- 같은 8자 이상 문장은 한 글에서 한 번만 사용하고, `절대`, `무조건`, `호구`는 각각 최대 1회로 제한한다.

## 레이아웃·강조·이미지

HTML에서 관찰된 값:

| 항목 | 설명·비교형 | 경고·피해예방형 |
|---|---:|---:|
| 최상위 컴포넌트 | 19 | 18 |
| 내용/공백 문단 | 62/37 | 55/58 |
| 중앙/기본 정렬 | 86/13 | 107/6 |
| 표/인용/이미지 | 3/2/6 | 2/3/7 |
| 굵게/밑줄 | 8/2 | 38/12 |
| 이탤릭/취소선 | 0/0 | 0/0 |

수치는 할당량이 아니라 리듬의 증거다. 두 변형 모두 본문 대부분을 중앙 정렬하고 이미지 6~7개, 인용 소제목 2~3개를 사용한다.

### 설명·비교형 강조

- 기본 검정 `#000000`, 보조 진회색 `#555555`
- 검증된 핵심어만 빨강 `#ff0010`
- 표 헤더는 회색 `#e2e2e2`, 연락표는 연두 `#e3fdc8`
- 핵심 결론은 회보라 `#f5f5f8`
- 노란 최상위 강조는 기본적으로 사용하지 않는다.

### 경고·피해예방형 강조

- 위험 문구는 굵게 또는 빨간색으로 강조한다. 네이버 복사용 HTML에는 밑줄을 사용하지 않는다.
- 피해 가능성이나 즉시 확인할 행동은 빨강 `#ff0010`으로 표시한다.
- 글 전체의 최중요 경고 1~2개만 노랑 `#ffef34` 배경을 사용한다.
- 요약표와 연락표 헤더는 파랑 `#28e1ff`을 사용할 수 있다.
- 모든 문장을 강조하지 말고 경고와 해결 행동 사이에는 일반 문단을 둔다.

### 표와 이미지

- 표는 초반 요약, 중간 비교, 마지막 연락 정보 중 필요한 역할만 사용한다.
- 경고형은 항목별 인용 소제목 뒤에 관련 상황 또는 증거 이미지를 배치한다.
- 마스터에 이미지 슬롯이 있는데 실제 이미지가 없으면 해당 블록을 임의로 생략하지 말고 필요한 장면을 요청한다.
- 캡션은 실제 장면만 짧게 설명하고 정확 메인키워드 횟수를 채우는 용도로 쓰지 않는다.

## CTA와 사실 보호

마지막 논거에서 독자가 할 행동이 이미 분명하면 별도 요약을 만들지 않는다. 본문 안의 선택권 문장은 필요한 경우에만 한 번 쓰고, 대표 전화와 네이버 예약은 고유 결론 뒤 고정 마감 블록에서만 안내한다.

자극형에서는 `사기`, `불법`, `폰팔이`, `호구`, `무조건`, `절대`를 적극 사용할 수 있다. 단, 근거 없는 표현은 특정 대상에 대한 사실 단정이 아니라 검색어·질문·일반적 위험 패턴·행동 지침으로 사용한다.

정책 날짜, 계약 규칙, 가격, 판매량, 수상, 후기와 특정 개인·업체의 책임은 매 글마다 확인한다.

## 검수

- 브랜드를 지워도 독자가 가져갈 정보가 남는가
- 설명형 또는 경고형을 목적에 맞게 선택했는가
- 각 기준에 이유와 확인·회피 행동이 있는가
- 세 기준의 역할과 마지막 행동이 서로 다른가
- 동일 문장이나 같은 의미의 범용 명령이 반복되지 않았는가
- 표와 이미지가 정보나 경고를 실제 판단 기준으로 바꾸는가
- 변형에 맞는 강조 밀도를 사용했는가
- 자극형이라면 제목과 도입이 충분히 강한가
- 강한 단어마다 확인 질문이나 회피 행동이 이어지는가
- 확인되지 않은 특정 업체 비방, 법적 단정, 정책·가격·수치를 만들지 않았는가
- 원문의 주제 내용은 새 제목으로 치환하고 말투·구조·문장 역할은 유지했는가
