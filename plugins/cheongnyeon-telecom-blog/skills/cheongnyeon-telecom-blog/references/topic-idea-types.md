# 외부 주제·제목 아이디어 라이브러리

## 역할 분리

한 편의 글에는 서로 섞이지 않는 세 출처가 있다.

1. **주제·제목 아이디어 출처**: `sungji_dongtan` 공개 글 188편에서 추출한 제목 장치, 독자 질문, 답변 의제만 사용한다.
2. **말투·구조·꾸미기 출처**: `cjdsus4444`의 선택한 청년통신 주 마스터 1편만 사용한다.
3. **사실 출처**: `brand_facts.md`, `temporary_information.md`의 `사용 가능` 청년통신 사실만 사용한다.

외부 아이디어 글의 업체명, 인물, 지역, 판매량, 순위, 가격, 환불, 후기, 경력, 전화번호, 방송·수상 주장은 제목과 본문 어디에도 옮기지 않는다. 외부 글은 청년통신 글의 마스터도 아니며, 문장·문단 순서·사진·색·밑줄·표를 가져오는 출처도 아니다.

## 압축 라이브러리

- 파일: `topic-idea-library.json`
- 수집기: `scripts/build_topic_idea_library.py`
- 현재 공개 글 수: 188편
- 저장 항목: 원문 링크·제목, 발행일, 주 유형, 보조 각도, 제목 패턴, 독자 질문, 답변 의제, 호환 가능한 청년통신 마스터
- 저장하지 않는 항목: 원문 전체 본문, 문장 복사본, 외부 업체 사실 팩

실행할 때 188편을 다시 읽지 않는다. `scripts/select_topic_idea.py`가 최근 3개의 `ideaType`, `titlePatternId`, `ideaReferenceUrl`과 겹치지 않는 후보를 우선해 한 편만 반환한다. 정밀작성모드에서 선택지를 제시할 때만 최대 3편을 반환한다.

## 주 유형

| ID | 의미 | 글이 답해야 할 것 |
|---|---|---|
| `fraud-prevention` | 사기·호갱 피해예방 | 경계할 말, 생기는 손실, 계약을 멈추고 확인할 행동 |
| `price-mechanism` | 가격 구조·저렴한 이유 | 같은 기종 가격이 달라지는 원인, 운영 구조, 동일 조건 비교법 |
| `purchase-checklist` | 구매 기준·체크리스트 | 계약 전 구체 항목, 놓쳤을 때 결과, 현장 질문 |
| `store-trust-intro` | 업체·신뢰 소개 | 광고 불신, 검증 가능한 청년통신 근거, 일반적인 매장 선택법 |
| `plan-contract-explainer` | 요금제·결합·약정 정보 | 제도의 뜻, 이익과 예외, 계약서 확인 항목 |
| `switching-comparison` | 번호이동·기기변경 비교 | 두 방식 차이, 예외 비용, 총비용 판단 |
| `visit-case-story` | 방문 이유·사례 | 방문 이유, 운영 근거, 다른 매장에도 적용할 선택 기준 |
| `insider-story` | 대표 철학·내부자 관찰 | 대표 입장, 운영 선택의 이유, 구매자 행동 |
| `launch-stock` | 신제품·사전예약·재고 | 출시 조건, 재고·수령 시점, 구매 전 확인 항목 |
| `faq-aftercare` | FAQ·사후관리 | 준비 조건, 진행 중 실패 지점, 개통 후 행동 |

`launch-stock`과 `faq-aftercare`처럼 호환 가능한 청년통신 꾸미기 마스터가 아직 없는 유형은 자동 완성에서 제외한다. 정밀작성모드에서 선택했다면 임의 구조로 쓰지 않고 해당 유형 청년통신 대표글을 요청한다.

## 실행 순서

1. 메인키워드를 확정한다.
2. `select_topic_idea.py`로 아이디어 글 1편을 고른다.
3. 선택된 `titlePatternId`, `readerQuestion`, `answerAgenda`로 새 제목의 약속을 설계한다.
4. 숫자·권위·보장 표현은 외부 글에서 가져오지 않고 청년통신 근거가 있는 것만 넣는다.
5. `validate_title.py`를 통과시킨다.
6. 선택 결과의 `writingMasterId`에 해당하는 청년통신 원문 한 편을 읽고 구조·말투·꾸미기·사진을 1대1 재구성한다.
7. 발행 완료 뒤 `record_article_state.py`로 선택 차원을 기록하고 최근 3개만 유지한다.

## 제목 금지 예

- `가격보다 상담 과정을 먼저 볼 이유`
- `싼 곳이 의심될 때 확인할 근거`
- `좋은 매장을 고르는 선택 기준`

구매자가 제목만 읽고 얻을 답을 상상하기 어려운 추상 제목은 사용하지 않는다. `이 말 들으면 계약 멈추세요`, `같은 폰인데 가격 다른 진짜 이유`, `개통 전 놓치는 조건 3가지`처럼 손실·상황·질문·구체 명사가 드러나는 제목으로 바꾼다.
