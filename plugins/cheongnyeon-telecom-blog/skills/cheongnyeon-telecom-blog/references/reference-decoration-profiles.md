# 레퍼런스 꾸미기 1대1 재구성

## 목적

HTML을 만들 때 선택한 글쓰기 마스터 한 편이 꾸미기 마스터도 동시에 결정한다. 별도의 공통 청록색 템플릿이나 다른 글의 예쁜 요소를 섞지 않는다.

측정값과 프로필은 `assets/reference-decoration-profiles.json`을 사용한다. 프로필이 없는 마스터를 선택했다면 해당 원문의 `PostView.naver` 안 `.se-main-container`를 확인해 프로필을 먼저 만든 뒤 HTML을 작성한다. 화면 캡처만 보고 색·정렬·표를 추측하지 않는다.

## 동일하게 유지할 항목

- SmartEditor 구성요소의 종류와 순서: text, image, table, quotation, imageGroup, horizontalLine, placesMap
- 전체 문단에서 중앙 정렬과 기본 정렬이 쓰이는 비율
- 한 의미 덩어리 사이의 빈 문단 수와 호흡
- 기본 글자, 큰 후킹, 소제목, 연락처에 쓰인 크기 단계
- 검정·회색·빨강과 배경색의 실제 팔레트
- 굵게, 밑줄, 색상, 배경 하이라이트가 등장하는 문장 역할과 횟수
- 표의 개수, 위치, 행 수, 헤더 배경, 본문 셀 구성
- 인용구의 개수, 위치, 기본형·포스트잇형 같은 종류와 출처 줄
- 사진·콜라주·캡션·지도의 위치와 크기 역할
- `mediaSlots`에 등록된 사진의 정확한 원본 URL, 구성요소 위치, 단독·콜라주 순서
- 미리보기와 네이버 복사 HTML 모두 등록된 `sourceUrl`의 공식 원본 URL을 `src`로 사용한다. 사용자 컴퓨터의 로컬 이미지 파일을 요구하지 않는다.
- 마감 표와 연락처의 배치 순서

새 제목의 문장이 길어져도 다른 장식으로 바꾸지 않는다. 같은 역할의 문장을 같은 장식 슬롯에 넣고, 500px 기준 1~2줄이 되도록 의미 경계에서만 줄바꿈한다.

## 한 마스터 원칙

`decorationMasterReferenceId`는 항상 `masterReferenceId`와 같아야 한다.

- 경고형 본문에 가격형 포스트잇 인용구를 가져오지 않는다.
- 마스터에 없는 요약 카드, 체크리스트, 배너, 둥근 박스를 추가하지 않는다.
- 마스터가 네이버 기본 인용구를 쓰면 장식용 카드가 아니라 `<blockquote>`와 짧은 출처 줄로 재현한다.
- 마스터가 표를 쓰면 실제 `<table><tbody><tr><td>`로 만들고 일반 `<div>` 박스로 바꾸지 않는다.
- 마스터 프로필에 `mediaSlots`가 있으면 새 글의 주제와 관계없이 등록된 같은 `sourceUrl` 사진을 같은 슬롯에 사용한다. 원격 URL이 실패해도 사용자 컴퓨터의 다른 사진이나 로컬 경로로 바꾸지 않고 원본 URL 문제를 보고한다.
- `mediaSlots`가 없는 마스터가 사진을 쓰는 경우에만 검증 자산을 요청한다.

## 네이버 복사 안전 예외

사용자가 승인한 최신 복사 안전 기준을 적용한다.

- 원문의 실제 밑줄은 같은 문장 역할과 횟수에 `<u data-reference-underline-role="...">`로 유지한다. 프로필에 없는 문장에는 밑줄을 추가하지 않는다.
- 빈 줄은 `-`, `ㅡ`, `—`, `&nbsp;`, 빈 `<p>`, `<p><br></p>`로 만들지 않고 U+2060 한 글자가 든 중앙 문단으로 만든다.
- 표 헤더의 청록색은 셀 배경 한 겹만 사용한다. 내부 `<span>`에 다른 배경색을 중첩하지 않는다.
- Naver의 `se-*` 클래스와 UUID는 복제하지 않는다. 의미가 같은 표준 HTML과 인라인 스타일로 재구성한다.
- 네이버 본문에서 B·U가 켜진 상태가 복사 서식을 덮어쓸 수 있으므로 복사 페이지와 완료 메시지에 B·U 해제 안내를 둔다.

이 예외 외에는 ‘더 깔끔하게 보인다’는 이유로 색, 정렬, 표, 인용구, 강조 위치를 바꾸지 않는다.

## 경고형 `warning-seller-lines-01`

원문: <https://blog.naver.com/cjdsus4444/223515173954>

- 후킹 3문장: 각각 검정, 굵게, 밑줄, 19px 상당.
- 판정 문장: `#ff0010` 빨강 굵게 + `#ffef34` 노란 배경.
- 본문: 거의 전부 중앙 정렬. 113개 문단 중 107개가 중앙 정렬이고 58개가 빈 호흡 문단이다.
- 신뢰 표: 5행. 첫 행 배경 `#28e1ff`, 나머지는 흰 셀, 핵심 사실만 빨강 굵게.
- 본론 소제목: 네이버 기본 인용구 3개와 짧은 출처 줄. 별도 배경 카드 없음.
- 본문 밑줄: 1절의 빨간 경고 1개와 판매자 약속 인용 1개. 다른 절에는 자동 밑줄을 추가하지 않는다.
- 사진: 원문과 같은 7장. 판정 뒤 상담 사진 1장, 신뢰 표 뒤 상담 사진 1장, 1절 뒤 재고 사진 1장, 2절 뒤 매장 전경 사진 1장, 3절 뒤 후기 캡처 3장 콜라주.
- 후기 콜라주: 첫 줄은 59.557%와 40.443% 두 칸, 둘째 줄은 100% 한 칸 순서로 유지한다.
- 연락 표: 2행. 첫 행 배경 `#28e1ff`, 둘째 행의 전화번호·부재 안내·예약 안내에 밑줄.
- 대표 팔레트: `#000000`, `#555555`, `#ff0010`, `#ffef34`, `#28e1ff`.

## 권위·방송형 `authority-broadcast-reason-01`

원문: <https://blog.naver.com/cjdsus4444/224275775634>

- 원문은 본문 문장을 한 개의 긴 `<p>` 안에 넣지 않고, 보이는 한 줄 또는 짧은 의미 덩어리마다 별도의 네이버 텍스트 문단으로 배치한다.
- 375px 모바일에서 보이는 짧은 2~3줄을 한 덩어리로 연속 배치하고, 덩어리가 끝날 때 U+2060 간격 문단을 정확히 1개 둔다. 이 `2~3줄 → 빈 줄 1칸` 리듬을 일반 본문 전체에 반복한다.
- 이 마스터는 문장 끝마다 `<br>`를 넣는 방식이 아니다. 새 글도 `<br>` 자동 분할을 하지 말고 원문처럼 `<p>` 순서와 간격을 재구성한다.
- article 전체와 일반 본문 문단에는 회색 배경을 깔지 않는다. `#f5f5f8`은 원문에서 실제로 강조된 특정 문장 슬롯에만 두고, 복사 과정에서 일반 문장 전체로 번지지 않게 한다.
- 표·인용구·사진 캡션 안의 줄바꿈은 해당 컴포넌트 원본의 방식만 유지한다.
- 긴 새 문장은 원문의 줄 역할에 맞춰 의미가 끊기는 지점에서 두 개 이상의 짧은 텍스트 문단으로 나눈다. 한 `<p>`가 모바일에서 두 줄로 감기면 두 줄로 계산하고, 빈 줄 없이 4줄 이상 이어지지 않게 한다.

## HTML 작성 순서

1. `type-reference-library.md`에서 주 마스터 한 편을 선택한다. 보조 원문을 읽더라도 꾸미기 판단에는 사용하지 않는다.
2. 주 마스터와 같은 ID의 꾸미기 프로필을 읽고 `decorationMasterReferenceId`를 고정한다.
3. 원문의 구성요소 순서와 문장 역할을 합쳐 하나의 장식 맵을 만들고 `mediaSlots`의 원본 URL과 위치를 고정한다.
4. 원고 문장을 해당 슬롯에 넣고 의미 경계에서만 줄바꿈한다.
5. 인라인 스타일과 표준 HTML로 복사 루트를 만든다.
6. `scripts/validate_reference_decoration.py HTML --profile 마스터ID`를 실행해 사진 URL·순서·위치와 밑줄 역할·횟수까지 검사한다.
7. 580px와 375px에서 시각 검수하고 실제 복사 버튼을 누른다.

프로필이 없는 상태, 선택한 주 마스터와 다른 프로필, 장식 검문 실패 상태에서는 HTML 완성본을 제공하지 않는다. 보조 원문은 최대 1편까지 읽을 수 있지만 꾸미기 프로필을 추가로 만들거나 섞지 않는다.
