## 출처와 정제 범위

- 판매자 멘트형 기준 글: <https://blog.naver.com/cjdsus4444/223515173954>
- 독자 반론형 기준 글: <https://blog.naver.com/cjdsus4444/223916429310>
- 기준 발행일: 2024-07-16, 2025-06-30
- 사용자 지정 명칭: `반박분석 3멘트`

본문을 분석할 때 프로필, 작성일, `이 포스트로 클립 만들기`, `URL 복사`, `통계`, `본문 기타 기능`처럼 네이버 화면이 붙인 문구는 버린다. 사진 사이에서 반복되는 SEO용 매장명은 위치·호흡 참고로만 보고, 새 원고의 독립 문장으로 복제하지 않는다.

두 글에 나온 연간 5,000대·6,000대, 하루 문의 81건, 단통법 폐지 예정 같은 숫자와 시점 문장은 그 글이 발행된 당시의 역사적 사실 또는 문체 자료다. 새 글에는 `brand_facts.md`와 `temporary_information.md`에서 같은 항목의 최신값만 사용한다. 문체를 배운다는 이유로 오래된 값을 현재 사실로 되살리지 않는다.

이 자료는 선택한 마스터에 `반박분석 3멘트`가 있을 때만 사용한다. 마스터의 독자 본능을 먼저 말하는 방식, 반론을 넘기는 순서, 문장 수, 문장 호흡, 긴장감과 양보의 배치를 그대로 유지하고 새 제목의 멘트와 답으로 치환한다. 마스터에 3멘트가 없으면 이 기능을 추가하지 않는다.

## 공식 정의

`반박분석 3멘트`는 제목을 본 독자 머릿속의 말 또는 실제 판매 현장에서 들을 법한 말을 세 문장으로 먼저 보여 주고, 각 문장을 본문의 서로 다른 반박으로 회수하는 전개다.

선택한 마스터가 같은 순서를 가질 때의 구조 지도는 다음과 같다.

`제목에 맞는 멘트 3개 → 즉시 반응 → 화자의 위치와 작성 이유 → 소비자 마음 2차 후킹 → 세 반박 또는 원리 분석 → 선택 행동 → 연락·예약 마감`

마스터가 이 순서를 사용하면 새 글도 그대로 유지한다. 화자 소개, 신뢰 근거, 독자 이익 약속의 위치를 바꾸거나 기능을 빼지 않는다. 멘트 세 개는 새 제목의 내용으로 치환하고 본문에서 세 개 모두 같은 대응 위치에서 답한다.

## 두 가지 하위 유형

### 1. 판매자 멘트 3개형

선택한 마스터가 `판매자 멘트 3개형`일 때 사용한다.

권장 흐름:

`판매자가 할 법한 말 3개 → 단호한 판정 → 대표의 현장 위치·이해관계 또는 작성 이유 → 선택한 신뢰 근거 → 1·2·3 반박 → 바로 할 행동 → 비교를 먼저 권하는 결론 → 연락·예약`

- 세 문장은 할부, 반납, 요금제처럼 서로 다른 손실 경로를 가리켜야 한다.
- 실제 인용 자료가 없으면 특정 고객이나 특정 매장이 실제로 한 말처럼 쓰지 않는다. `이런 설명을 들었다면`, `계약할 때 자주 경계해야 할 말은`처럼 일반적·조건부 문장으로 둔다.
- 판정은 짧고 강하게 쓴다. 다만 `사기`, `호구`, `폰팔이`는 확인되지 않은 특정 업체나 개인을 지목하지 않고 일반적인 수법과 소비자 행동에만 연결한다.
- 각 번호의 서로 다른 틀과 손실 원리 순서는 마스터 그대로 유지하고, 새 제목의 세 위험으로 치환한다.

### 2. 독자 반론 3개형

선택한 마스터가 `독자 반론 3개형`일 때 사용한다.

권장 흐름:

`대표 또는 주제 소개 → 독자 머릿속 반론 3개 → 공감 → 선택한 신뢰 근거 → 소비자 마음 2차 후킹 → 시장 구조·가격 원리 → 다음 반론을 먼저 제시하고 답변 → 증거 또는 대표 서사 → 방문·비교 행동 → 연락·예약`

- 세 반론은 `자기 광고겠지`, `가격은 다 같지 않나`, `결국 다른 조건을 강요하겠지`처럼 의심의 층위가 달라야 한다.
- 공감의 문장 수·위치·강도는 마스터와 같게 유지하고, 공감 대상만 새 제목의 독자 생각으로 바꾼다.
- 첫 반론을 푼 뒤 `그렇다면 판매량은 어떻게 확인하지?`처럼 다음 질문을 앞질러 제시할 수 있다. 실제 고객 발화가 아니라 독자에게 직접 건네는 질문으로 표시한다.
- 권위는 결론을 대신하지 않는다. 방송·판매량·표창을 보여 준 뒤 반드시 가격이나 운영 차이가 생기는 원리를 설명한다.
- 본론 직전에는 [reader-commitment-bridge.md](reader-commitment-bridge.md)에 따라 첫 세 반론 뒤에도 남은 한 가지 저항을 다시 분석한다. 선택 압박을 낮추고, 읽을 시간과 구체적 이익 또는 작성 명분을 새롭게 제시한다. 앞의 세 반론을 요약하지 않는다.

## 후킹 작성법

1. 마스터의 세 멘트가 각각 맡는 욕망·공포·의심 역할을 기록한다.
2. 새 제목에서 같은 역할을 맡을 판매자 말 또는 독자 생각을 만든다.
3. 세 멘트의 문장 수, 인용 형식, 문단 분리, 길이 리듬을 마스터와 동일하게 맞춘다.
4. 바로 다음 판정 또는 공감 문장의 역할과 강도를 마스터와 동일하게 유지한다.
5. 본문의 마스터 대응 소제목이나 반박 문단에 세 멘트의 답을 연결한다.

세 멘트를 만들 근거가 부족하거나 본문에서 세 답을 낼 수 없다면 이 모드를 쓰지 않는다. `3개` 형식을 맞추려고 사실이 없는 세 번째 반론을 만들지 않는다.

## 본문 반박 루프

각 논거에서 다음 다섯 기능 중 마스터에 실제로 있는 기능만 같은 순서로 사용한다.

`반론 또는 위험한 말 → 실제 작동 원리 → 예외·양보 → 고객에게 생기는 결과 → 지금 할 행동`

- 첫째·둘째·셋째 절의 끝맺음과 문단 수는 마스터 대응 절을 따른다.
- 마스터가 `질문 → 설명 → 확인하세요`를 반복하지 않았다면 새 글에도 그 반복을 만들지 않는다. 마스터에 있는 반복은 유지한다.
- `물론`을 쓸 때는 실제 예외를 인정한다. 반론을 무마하는 장식어로 쓰지 않는다.
- 제목이 순위를 약속하지 않으면 `1위·2위·3위`를 쓰지 않고 `1·2·3` 또는 질문형 소제목으로 둔다.

## 말투 지문과 자극 강도

- 현업 대표가 한 명의 고객에게 직접 말하는 1인칭 존댓말을 유지한다.
- 한 줄짜리 단호한 문장과 두세 줄짜리 원리 설명을 섞는다.
- 반론은 짧은 인용문 또는 직접 질문으로 던지고 답변은 구체적인 명사와 숫자로 푼다.
- 이해관계와 선택권 반환 문장은 마스터에 있을 때 같은 위치와 강도로 유지한다.
- 긴장을 만드는 문장과 대표의 분명한 판단은 마스터에 있는 수·위치·강도로 유지한다.
- 자극은 `독자가 잃을 수 있는 것`, `업계 설명의 허점`, `확인해야 할 행동`에 사용한다. 근거 없는 피해 규모, 가격 보장, 경쟁사 비방으로 강도를 만들지 않는다.
- 괄호 속 업계 대상 한마디의 유무·개수·위치는 마스터를 따른다. 문장은 새 제목의 실제 작성 명분으로 치환한다.
- `안녕하세요. SBS 생활의 달인에 출연한...`, `네 충분히 공감합니다`, `꼭 저희가 아니라도 좋습니다` 같은 문장의 위치와 역할은 마스터를 따른다. 새 제목과 최신 사실에 맞지 않는 명사·수치만 치환한다.

## 신뢰 근거 블록

마스터의 신뢰 근거 개수·형식·위치를 그대로 유지하고 내용만 제목과 가까운 최신 검증 사실로 교체한다. 다른 글의 신뢰 표나 사진 캡션을 추가하지 않는다.

생활의 달인 사진이 실제로 있으면 사진 바로 아래에 사실 캡션을 붙인다. 사진이 없으면 관련 없는 대체 이미지를 만들지 않는다. 표를 쓸 때는 네이버 SmartEditor가 받아들이는 기본 표 컴포넌트 역할로 만들고, 장식용 박스나 중첩 하이라이트로 대체하지 않는다.

## 내용 중복 방지

- 구조 반복을 피하려고 마스터의 화자 소개 위치, 신뢰 근거 개수·위치, 소제목 모양, 결론 행동을 바꾸지 않는다.
- 최근 글과 세 멘트의 주제 명사·사례·설명 내용이 겹치지 않게 새 제목의 내용으로 치환한다.
- 원문의 오탈자와 명백한 띄어쓰기 오류는 교정하되 말투와 문장 호흡은 유지한다.

## 선택 조건과 검문

선택한 마스터에 `반박분석 3멘트`가 있을 때 다음 조건을 검사한다. 마스터에 없으면 선택하지 않는다.

- 제목에서 독자의 의심 또는 경계할 판매자 말을 자연스럽게 세 개 도출할 수 있다.
- 세 멘트가 서로 다른 본능·손실·의문을 건드린다.
- 본문에서 각 멘트에 확인된 사실로 답할 수 있다.
- 강한 판정이 특정 업체에 대한 근거 없는 단정이 아니다.
- 현재 사실만 고른 신뢰 근거가 마스터와 같은 개수·형식·위치다.
- 화자 소개와 신뢰 근거가 마스터와 같은 위치·문장 역할이다.
- 마지막의 요약 유무와 길이가 마스터와 같다.
- 고유 결론 뒤 대표 전화와 네이버 예약 마감은 한 번만 둔다.
