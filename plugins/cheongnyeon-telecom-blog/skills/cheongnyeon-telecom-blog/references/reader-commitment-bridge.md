## 목적과 위치

`소비자 마음 2차 후킹`은 선택한 마스터 글에 해당 블록이 있을 때, 그 블록의 기능을 새 제목에 맞게 치환하기 위한 분석 기준이다. 첫 후킹이 독자의 의심을 알아맞힌 뒤, 본론을 시작하기 직전에 남아 있는 이탈 이유를 한 번 더 해소한다.

이 문서만 보고 2차 후킹을 새로 추가하지 않는다. 마스터에 2차 후킹이 있을 때만 마스터와 같은 위치·문장 수·기능 순서로 사용하고, 마스터에 없으면 생략한다.

첫 후킹과 역할이 다르다.

- 첫 후킹: `지금 독자가 무슨 생각을 하는지 안다`
- 2차 후킹: `그래도 왜 이 글을 계속 읽어야 하는지 답한다`

권장 위치:

`첫 후킹 또는 반박분석 3멘트 → 공감·화자 위치 → 선택한 신뢰 근거 또는 사진 → 소비자 마음 2차 후킹 → 본론 첫 답`

신뢰 근거는 제목에 따라 2차 후킹 뒤로 옮길 수 있다. 중요한 것은 2차 후킹이 본론의 첫 소제목 바로 앞에서 독자의 남은 저항을 해소하는 것이다.

## 기준 문단에서 추출한 기능

기준 문단:

`꼭 저희가 아니라도 좋으니`는 선택 압박을 낮춘다.

`이 글만 2분 집중해서`는 독자가 지불할 시간을 작게 만든다.

`최소 30만 원은 저렴하게`는 읽고 얻을 결과를 구체화한다.

괄호 속 동종업계 문장은 `왜 굳이 이 이야기를 공개하는가`라는 작성 명분과 긴장을 만든다.

이 네 기능 중 마스터에 실제로 있는 기능만 같은 순서와 문장 수로 유지한다. 새 제목의 저항·이익·작성 명분으로 내용을 치환한다.

## 작성 전 소비자 마음 재분석

첫 후킹을 쓴 뒤 다음 네 질문에 내부적으로 답한다.

1. 독자가 첫 문단까지 읽고도 떠나려는 가장 큰 이유는 무엇인가?
2. 독자는 이 글을 광고, 어려운 설명, 시간 낭비, 과장 중 무엇으로 의심하는가?
3. 끝까지 읽으면 독자가 실제로 얻는 한 가지 결과는 무엇인가?
4. 지금 읽지 않으면 놓칠 수 있는 결정·금액·계약 항목은 무엇인가?

답을 다음 구조로 기록한다.

```json
{
  "remainingResistance": "첫 후킹 뒤에도 남은 한 가지 저항",
  "timeCost": "30초 | 1분 | 2분 | 미표기",
  "readerPayoff": "확인된 사실로 약속할 수 있는 한 가지 결과",
  "costOfSkipping": "읽지 않았을 때 놓칠 수 있는 구체 항목",
  "writerReason": "왜 대표가 이 내용을 공개하는지 확인된 이유",
  "industryTension": "none | restrained | strong"
}
```

첫 후킹에서 이미 말한 의심을 `remainingResistance`에 다시 쓰지 않는다. 새로 남은 저항이 없으면 2차 후킹을 한 문장짜리 이익 약속으로 줄인다.

## 마스터 블록 해석 공식

다음 다섯 기능 중 마스터 2차 후킹에 실제로 들어 있는 기능만 기록한다. 새 글을 위해 기능을 새로 고르지 않는다.

1. **선택 압박 해제**: 청년통신을 고르라고 재촉하는 글이 아님을 밝힌다.
2. **짧은 시간 요청**: 읽는 데 필요한 시간을 작고 구체적으로 제시한다.
3. **독자 이익 약속**: 읽고 나면 알게 될 질문, 계산, 계약 항목, 가격 원리를 보여 준다.
4. **놓칠 비용**: 모르고 계약했을 때 생길 수 있는 구체적인 혼란이나 손실 경로를 말한다.
5. **작성 명분·업계 긴장**: 왜 판매자인 화자가 이 내용을 공개하는지 설명한다.

마스터가 이 순서를 쓴 경우의 해석:

`선택 압박 해제 → 짧은 시간 요청 → 검증 가능한 독자 이익 → 필요한 경우 작성 명분·업계 긴장 → 본론`

다른 마스터 순서의 해석 예시:

- `남은 의심 한 문장 → 독자 이익 → 본론`
- `놓칠 비용 → 1분 요청 → 확인할 실제 항목 → 본론`
- `작성 명분 → 선택권 반환 → 본론`

마스터의 기능 수와 문장 수를 그대로 유지한다. 마스터가 2문장이면 2문장, 괄호 문단을 포함한 6문장이면 6문장으로 쓴다.

## 유형별 선택

아래 내용은 선택한 마스터의 2차 후킹 문장을 새 제목으로 치환할 때 의미를 해석하는 자료다. 마스터에 없는 유형 공식을 새로 적용하지 않는다.

### 경고·피해예방형

- 남은 저항: `설마 실제로 그런 일이 있겠어?`
- 핵심 기능: 놓칠 비용 + 짧은 시간 + 회피 행동
- 약속 가능한 이익: 계약서에서 볼 항목, 거절할 문장, 매장을 나와야 할 신호
- 업계 긴장: 일반적인 수법 공개에만 연결하고 특정 업체를 지목하지 않는다.

권장 흐름:

`과장처럼 들릴 수 있다는 인정 → 1~2분 요청 → 계약 전에 피할 한 가지 손실 약속 → 본론`

### 가격·권위형

- 남은 저항: `결국 자기 매장이 싸다는 광고 아닌가?`
- 핵심 기능: 선택 압박 해제 + 가격 구조 이익 + 작성 명분
- 약속 가능한 이익: 가격 차이가 생기는 원리, 판매량과 수수료 관계, 판매량을 확인하는 방법
- 업계 긴장: 확인된 시장 구조를 공개하는 이유로만 사용한다.

권장 흐름:

`매장 선택권 반환 → 2분 요청 → 가격 구조를 알았을 때 얻는 이익 → 필요한 경우 업계 대상 한마디 → 본론`

### 설명·비교형

- 남은 저항: `내용이 복잡해서 읽어도 모르겠다`
- 핵심 기능: 난이도 낮추기 + 비교 결과 약속
- 약속 가능한 이익: 두 견적에서 먼저 볼 숫자, 총비용 계산법, 같은 조건으로 맞추는 방법
- 업계 긴장: 기본적으로 사용하지 않는다.

### 사전예약·재고형

- 남은 저항: `지금 예약해야 하는지, 기다려도 되는지 모르겠다`
- 핵심 기능: 판단 시점 + 확인 가능한 재고·일정 정보
- 시점이 지난 수량·혜택·예약 조건을 현재 긴급성으로 만들지 않는다.
- 업계 긴장: 공급·재고 사실이 실제로 있을 때만 절제해 사용한다.

### FAQ·사후관리형

- 남은 저항: `내 질문 하나 때문에 긴 글을 읽어야 하나?`
- 핵심 기능: 답변 위치를 빠르게 약속 + 불안 해소
- 1~2문장으로 끝내고 업계 긴장을 사용하지 않는다.

### 대표 서사형

- 남은 저항: `성공 자랑이나 홍보 이야기 아닌가?`
- 핵심 기능: 이해관계 인정 + 독자가 얻을 운영 원칙 + 인간적 작성 이유
- 가격 절약 약속보다 대표가 어떤 선택을 했고 고객이 무엇을 기준으로 볼 수 있는지 연결한다.

## 문장 작성 규칙

- 마스터의 선택 압박 해제 문장이 있으면 같은 말투와 위치를 유지하고 새 제목의 맥락으로 치환한다. 없으면 추가하지 않는다.
- 마스터가 `2분`을 쓰면 현재 글도 같은 시간 요청 역할을 유지한다. 사실상 다른 분량으로 바뀌어 거짓이 되는 경우에만 같은 문장 역할 안에서 시간을 조정한다.
- 이익 약속에는 본론에서 실제로 회수할 명사를 쓴다. `도움이 됩니다`, `좋은 정보를 얻습니다`처럼 비어 있는 약속을 쓰지 않는다.
- 본론 첫 소제목은 2차 후킹에서 약속한 답을 바로 시작한다. 신뢰 표나 긴 자기소개로 다시 지연하지 않는다.
- 괄호 문단의 유무·개수·위치는 마스터를 그대로 따른다.

## 사실과 자극 안전선

- `최소 30만 원 절약`, `무조건 저렴`, `이 글을 읽으면 돈을 아낀다`처럼 독자의 결과를 보장하려면 그 결과 자체를 뒷받침하는 현재 근거가 있어야 한다.
- `월 500대와 50대 매장의 수수료 차이가 보통 30만 원`이라는 사실을 `모든 독자가 최소 30만 원 절약한다`로 확대하지 않는다.
- 단통법은 현재 `2025년 7월 22일 폐지됐다`는 시제를 사용한다. `폐지될 지금`, `폐지 예정`을 현재 문장으로 쓰지 않는다.
- 동종업계 대상 문장은 긴장을 위한 장치이지 경쟁사를 범죄자나 신고자로 단정하는 근거가 아니다.
- `제발 신고하지 마세요`, `어차피 다시 올립니다`를 자동 문구로 쓰지 않는다. 실제 글의 작성 명분과 제목에 도움이 될 때만 같은 기능을 새 문장으로 구현한다.
- 사실 근거가 부족하면 금액 대신 `할부원금`, `유지 기간`, `반납 조건`, `판매량과 수수료 구조`처럼 본론에서 확인 가능한 결과를 약속한다.

## 마스터 레퍼런스 안에서의 사용

정확도를 높이기 위해 이 문서를 독립 기능 모듈로 사용하지 않는다.

1. 제목과 같은 유형의 마스터 글 한 편을 먼저 선택한다.
2. 마스터에 2차 후킹이 있는지 확인한다.
3. 있으면 남은 저항·이익 약속·작성 명분의 역할, 문장 수, 괄호 문단 여부, 본론 직전 위치를 기록한다.
4. 기록한 순서와 말투를 유지한 채 새 제목의 저항과 이익으로만 치환한다.
5. 마스터에 없으면 이 문서를 적용하지 않고 2차 후킹도 추가하지 않는다.

같은 유형의 다른 글이나 별도의 후킹 글에서 문장을 가져와 끼우지 않는다. 마스터 한 편이 전체 글의 말투와 구조를 결정한다.

## 반복 방지와 검문

- 선택한 마스터에 2차 후킹이 실제로 있는가
- 마스터와 같은 위치·문장 수·기능 순서인가
- 첫 후킹과 2차 후킹이 같은 의심을 반복하지 않는가
- 2차 후킹이 본론에서 얻을 새 이익을 구체적으로 약속하는가
- 금액·기간·절약 결과에 현재 근거가 있는가
- 업계 긴장 문장이 제목과 작성 이유에 실제로 필요한가
- 2차 후킹 뒤 본론을 바로 시작하는가
- 마스터의 선택 압박 해제 문장, 시간 요청, 괄호 문단의 위치와 역할을 유지했는가
- 다른 레퍼런스의 후킹이나 마무리를 자동으로 섞지 않았는가
- 원문의 주제 문장은 새 제목 내용으로 바꾸고 문장 역할과 말투 리듬은 유지했는가
