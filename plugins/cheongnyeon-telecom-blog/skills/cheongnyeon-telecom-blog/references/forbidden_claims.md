# 근거 없이는 사용할 수 없는 주장

다음 내용은 이번 사용자 자료, `cjdsus4444` 공식 블로그의 최신 관련 게시물, `brand_facts.md`, `temporary_information.md` 중 현재 `사용 가능` 근거가 없으면 제목·본문·CTA에 쓰지 않는다. 공식 블로그 사실은 외부 검증이나 사용자 재확인을 요구하지 않는다.

- 가격, 할인액, 할인율, 지원금 수치
- 최저가, 업계 최고, 지역 1위, 상위 비율
- 판매량, 문의량, 방문자 수, 고객 수
- 고객 후기, 고객 사례, 실제 상담 발화
- 방송 출연, 표창, 수상, 인증
- 대표·직원의 경력과 운영 기간
- 경쟁 매장과의 가격 차이
- 예약 혜택, 행사, 사은품
- 재고 보장, 즉시 개통 보장
- 서비스·환불·배상 보장
- 현재 통신 정책, 요금제 가격, 유지 기간

## 검증 규칙

1. 주장의 정확한 문구와 숫자를 사실 레코드에 연결한다.
2. 근거의 기간, 대상, 지점, 상품 범위를 확인한다.
3. `일부`, `최대`, `조건 충족 시` 같은 제한을 삭제하지 않는다.
4. 외부 스타일 예시에만 있는 주장은 사실 레코드로 만들지 않는다. 단, `cjdsus4444` 게시물의 청년통신 사실은 게시일 최신성 규칙으로 사실 레코드에 등록한다.
5. 근거가 없으면 표현을 약하게 바꾸어 남기지 말고 삭제하거나 자료를 요청한다.

## 고객 질문과 사례

`많이 물어보십니다`, `실제 고객이 말했습니다`, `최근 이런 상담이 있었습니다`도 경험 주장이다. 확인된 실제 재료가 없으면 `이런 점이 궁금하실 수 있습니다`처럼 일반 독자의 의문으로만 쓴다.
