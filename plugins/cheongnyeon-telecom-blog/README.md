# 청년통신 블로그 작성 플러그인

청년통신 네이버 블로그 원고를 자동모드 또는 정밀작성모드로 작성하고, 네이버 블로그에 붙여넣기 쉬운 HTML을 현재 사용자의 바탕화면에 출력합니다.

## 포함 기능

- 자동모드와 정밀작성모드 인터뷰
- 검증된 청년통신 브랜드 사실 적용
- 유형별 청년통신 레퍼런스 구조와 말투 적용
- 모바일 가독성을 고려한 짧은 줄과 2~3줄 단락
- 레퍼런스 블로그 원본 이미지 URL과 동일한 배치 순서 적용
- 로컬 청년통신 이미지가 없는 컴퓨터에서도 실행
- 네이버용 HTML 복사 버튼이 있는 완성 파일 생성
- 최근 작성한 유형 3개만 보관해 자동모드의 주제 중복 방지

## 사용

새 Codex 작업에서 다음처럼 요청합니다.

1. `청년통신 블로그 글을 자동모드로 작성해줘.`
2. `청년통신 블로그 글을 정밀작성모드로 작성해줘.`

HTML은 기본적으로 현재 사용자의 `Desktop` 폴더에 저장됩니다. 저장 위치를 바꾸려면 `CHEONGNYEON_OUTPUT_DIR` 환경 변수를 사용합니다.

## 이미지 동작

이미지 파일은 플러그인에 포함하지 않습니다. 선택된 청년통신 레퍼런스 글에 기록된 원본 이미지 URL을 같은 위치와 순서로 사용합니다. 원본 블로그에서 이미지가 삭제되거나 외부 접근이 차단되면 해당 이미지는 표시되지 않을 수 있습니다.
